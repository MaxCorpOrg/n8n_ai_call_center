# 09. Эксплуатация И Безопасность

## Операционные правила
- Работать только с указанным пользователем файлом.
- Перед массовым обновлением иметь резервную копию файла.
- Не изменять структуру шаблона без согласования.

## Сетевые ограничения
- Ограничивать частоту запросов.
- Использовать таймауты и повторные попытки.
- Избегать агрессивного сканирования источников.

## Безопасность данных
- Не хранить API-ключи в документации.
- Не публиковать сырые дампы с персональными данными вне рабочей среды.
- В отчёте показывать только необходимый минимум.

## Комплаенс
- Использовать только открыто доступные контактные данные.
- Уважать условия использования источников.
- Не обходить ограничения доступа и защиту.

## Аварийный чеклист
1. Проверить доступность источников.
2. Проверить валидность текущего xlsx.
3. Перезапустить сбор с меньшим параллелизмом.
4. Сформировать частичный результат и сообщить остаток.
