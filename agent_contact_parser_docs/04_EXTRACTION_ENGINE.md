# 04. Движок Извлечения

## Этапы извлечения
1. Получить HTML выдачи.
2. Извлечь идентификаторы организаций.
3. Загрузить страницы карточек.
4. Извлечь `company_name`, `phone_primary`, `source_url`.
5. Сформировать сырой список записей.

## 2GIS: алгоритм
1. Найти `firm_id` через regex `/firm/(\d+)` в выдаче.
2. Открыть `https://2gis.ru/moscow/firm/<firm_id>`.
3. Извлечь блок `initialState`.
4. Декодировать `unicode_escape`.
5. Найти профиль с `contact_groups`.
6. Забрать контакты типа `phone`.

## Yandex: алгоритм
1. Открыть страницу поиска по Москве.
2. Последовательно искать JSON-объекты `{"type":"business"...}`.
3. Для каждой карточки взять `title` и `phones`.
4. Формировать запись на каждый валидный телефон.

## Минимальная структура записи
```json
{
  "company_name": "Название",
  "phone_primary": "+7XXXXXXXXXX",
  "source": "2gis|yandex",
  "source_url": "https://..."
}
```

## Ошибки и обработка
- сеть: retry + timeout
- parse error: пропустить запись, логировать причину
- пустой телефон: запись отбрасывается
- пустое имя: подставить `Косметолог`
