## Быстрый запуск для агента
1. Проверить текущий Excel-файл с контактами.
2. Считать уже существующие телефоны (`phone_primary`).
3. Собрать новые контакты из 2GIS и Yandex (через firecrawl или прямой HTML-парсинг).
4. Нормализовать номера, убрать дубликаты.
5. Добавить только новые строки в `Лиды_обзвон`.
6. Проверить финальную уникальность телефонов и корректность формата.

## Базовые принципы
- Ничего не удалять без явного запроса.
- Новые контакты добавлять в конец листа.
- Все даты фиксировать в локальном формате `YYYY-MM-DD HH:MM:SS`.
- Поле `segment` всегда `Косметолог`.
- `city` для этого сценария всегда `Москва`.
