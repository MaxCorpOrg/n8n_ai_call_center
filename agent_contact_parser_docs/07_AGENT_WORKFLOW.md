# 07. Пошаговый Workflow Для Агента

## Шаг 1. Подготовка
- Открыть целевой `xlsx`.
- Считать все существующие телефоны в `set`.

## Шаг 2. Сбор данных
- Собрать пул организаций из 2GIS (несколько запросов/страниц).
- Собрать карточки Yandex по Москве.
- При наличии использовать firecrawl как fetch-слой.

## Шаг 3. Извлечение
- Из карточек получить названия и телефоны.
- Формировать единый список записей.

## Шаг 4. Очистка
- Нормализовать телефоны.
- Удалить невалидные записи.
- Удалить дубли и пересечения с Excel.

## Шаг 5. Запись
- Добавить нужное количество новых строк в конец листа.
- Заполнить дефолтные поля.

## Шаг 6. Контроль качества
- Сверить факт добавления (`N` строк).
- Проверить отсутствие дублей.
- Сохранить файл.

## Шаг 7. Отчёт пользователю
Сообщить:
- путь к файлу
- сколько добавлено
- диапазон строк
- итоговое число контактов
