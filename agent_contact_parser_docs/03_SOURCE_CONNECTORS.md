# 03. Источники И Коннекторы

## Поддерживаемые источники
1. `https://2gis.ru/moscow?...`
2. `https://yandex.com/maps/geo/moskva/...`

## Роли источников
- 2GIS: широкий список организаций, богатые контактные данные в профиле фирмы.
- Yandex Maps: дополнительные карточки с прямыми телефонами.

## Firecrawl
Firecrawl может использоваться как первичный fetch-слой, если локально доступен и настроен.

Проверки:
- наличие CLI/SDK
- наличие ключа доступа
- успешная загрузка страницы

Fallback при отсутствии firecrawl:
- `requests` + парсинг HTML локально.

## Технические особенности
- 2GIS часто хранит полезные данные в `initialState = JSON.parse('...')`.
- Yandex может содержать карточки вида `{"type":"business", ...}` внутри HTML.
- На поиск влияет query + zoom + позиция карты.

## Стратегия обхода
- Использовать несколько запросов (`косметолог`, `косметология`, `косметологический центр`).
- Для 2GIS обходить страницы выдачи (`/page/1..N`) и затем карточки `/firm/<id>`.
- Для Yandex извлекать карточки из поисковой выдачи по Москве.

## Риски источников
- rate limit / капча
- неполный ответ при коротком таймауте
- изменение структуры HTML/JS
