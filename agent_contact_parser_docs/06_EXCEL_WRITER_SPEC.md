# 06. Спецификация Записи В Excel

## Лист
Целевой лист: `Лиды_обзвон`.

## Ключевые колонки
- `company_name`
- `phone_primary`
- `city`
- `segment`
- `source_record_key`
- `created_at`, `updated_at`

## Заполняемые значения по умолчанию
- `source_system`: `xlsx_import`
- `city`: `Москва`
- `segment`: `Косметолог`
- `followup_count`: `0`
- `max_touch_limit`: `3`
- `do_not_call`: `false`
- `agent_version`: `AI_CALL_AGENT_1`
- `last_updated_by`: `system_seed`

## Модель записи
- Добавление новых строк только после последней непустой строки.
- `source_record_key`: `row_<номер_строки>`.
- Даты в формате `YYYY-MM-DD HH:MM:SS`.

## Инварианты
- Не менять заголовки.
- Не сдвигать порядок колонок.
- Не удалять старые строки без явного запроса.

## Пост-проверка
1. Проверить число добавленных строк.
2. Проверить уникальность `phone_primary` по всему листу.
3. Проверить, что новые строки в ожидаемом диапазоне.
