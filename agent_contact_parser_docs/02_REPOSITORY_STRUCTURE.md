# 02. Структура Папок И Артефактов

## Базовый каталог проекта
`/home/max/n8n_ai_call_center`

## Важные директории
- ` Таблицы_контактов ` — рабочие Excel-таблицы и шаблон.
- `docs` — общая проектная документация.
- `scripts` — служебные скрипты проекта.
- `agent_contact_parser_docs` — текущая документация парсера для агентов.

## Типовые входы/выходы парсера
- Вход:
  - `.../Таблицы_контактов/пример_таблицы.xlsx`
  - `.../Таблицы_контактов/контакты_косметологов_москва_31.xlsx`
- Временные артефакты:
  - `/tmp/yandex_cosm.html`
  - `/tmp/2gis_cosm.html`
  - `/tmp/new_moscow_15_candidates.json`
- Выход:
  - обновлённый `xlsx` с новыми строками

## Рекомендованная структура скриптов (если выделять в код)
- `parsers/fetchers.py` — HTTP-загрузка страниц
- `parsers/yandex_parser.py` — извлечение карточек Yandex
- `parsers/twogis_parser.py` — извлечение профилей 2GIS
- `core/normalize.py` — нормализация телефонов/текста
- `core/dedup.py` — дедупликация
- `writers/excel_writer.py` — запись в Excel
- `qa/validators.py` — финальные проверки

## Политика именования
- Документация: `NN_TOPIC.md`
- Временные файлы: `*_preview.json`, `*_candidates.json`
- Итоговые файлы: понятное бизнес-имя + регион + число контактов
