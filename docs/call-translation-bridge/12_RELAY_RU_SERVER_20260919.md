# Шлюз ElevenLabs на новом сервере — 2026-09-19

## Как устроен

`n8n → HTTP relay → HTTPS ElevenLabs SIP outbound-call → JSON ответ n8n`.

Это небольшой сервис стандартной библиотеки Python. Он проверяет `X-Relay-Token`, добавляет серверный `xi-api-key` и передаёт JSON в `/v1/convai/sip-trunk/outbound-call`. Отдельной БД нет. Это шлюз исходящих вызовов, а не универсальный TTS/WebSocket-прокси.

Код: `scripts/eleven_outbound_relay_server.py`; безопасные шаблоны в `deploy/eleven-outbound-relay/`. Перенесены серверные отличия: тайм-аут 14 секунд и корреляционные поля журналирования. Повторные попытки по умолчанию выключены, чтобы неоднозначный ответ не вызвал повторный звонок.

## Проверено

Сервис active/enabled. `/health` возвращает 200 как локально, так и с сервера n8n. ElevenLabs `GET /v1/convai/agents` с перенесённым ключом возвращает 200 на обоих серверах. `GET /v1/user` возвращает 401 `missing_permissions`: этот ключ ограничен разрешениями, это не ошибка авторизации Agents API.

Три автономных теста проверяют health, 403 без токена, 400 при неверном JSON, передачу JSON/ключа тестовому upstream, проброс 429. Реальных звонков, SMS или платного синтеза не выполнялось. Реальный SIP-звонок не подтверждён этим тестом.

## Развёртывание ещё одного шлюза

1. Установить Python 3, скопировать скрипт в `/opt/eleven_outbound_relay.py`.
2. Приватно заполнить `/root/.eleven_outbound_relay.env` по шаблону; выдать уникальный relay token и ключ ElevenLabs с нужными разрешениями.
3. Разрешить порт только конкретному вызывающему серверу, установить unit и выполнить `systemctl enable --now eleven-outbound-relay`.
4. Проверить `/health`, ошибку без токена и доступ к разрешённому read-only API провайдера.
5. После проверки вызывающей стороны изменить её URL и передавать `X-Relay-Token`. Для публичного/расширенного доступа сначала использовать HTTPS или частную сеть: текущий совместимый HTTP-вариант не шифрует участок n8n→relay.

Не класть ключи в workflow JSON или GitHub. Журналы текущего relay содержат телефон и идентификаторы запроса; считать их приватными. Приватная копия исходных файлов находится в `/var/backups/project-migration-20260919/eleven-relay.tar.gz` на обоих серверах.
