# Pronunciation Dictionary для live-агента

## Что это

Здесь лежит рабочий словарь произношения для live-агента ElevenLabs по проекту `lipolong`.

Актуальная версия от `2026-04-04`:
- dictionary id: `NnZrxd6lJkbHKqW6w04N`
- version id: `K8lpSSKK1r5L3LiWHGPJ`
- source file: `lipolong_agent_base_2026-04-04.rules.json`

Hotfix этой версии:
- усилены точечно слова `липолонг` и `липолитиками`;
- для них добавлены дополнительные словоформы и более стабильный формат акцента.

## Как он собран

Словарь собран не вручную “на глаз”, а по реальному корпусу:
- `100` последних live-диалогов агента;
- текущий live-prompt агента;
- локальная русская knowledge base проекта.

Главная цель:
- зафиксировать произношение бренда как `липолонг`;
- выровнять частые термины, на которых голос чаще всего сбивается;
- не добавлять лишние слова, которых нет в реальных репликах агента.

## Что в него вошло

Словарь покрывает:
- бренд и его варианты: `ЛипоЛонг`, `LipoLong`, `lipolong`, `lipolong.com`;
- продуктовые слова: `липолитик`, `липолитиками`, `коррекция`, `инъекционные`, `процедуры`, `консультация`;
- частые B2B-слова: `менеджер`, `предоплата`, `безнал`, `премиум`;
- часто произносимые мессенджеры: `Telegram`, `WhatsApp`, `MAX`.

В словарь специально не включались `Mango` и `n8n`, потому что они не являются рабочими словами текущего голосового диалога с клиентом.

## Как обновлять дальше

Если снова всплывут кривые ударения:
1. снять свежий корпус последних звонков;
2. добавить только реально повторяющиеся проблемные слова;
3. создать новую версию словаря через `add-from-rules`;
4. переключить `pronunciation_dictionary_locators` у live-агента на новую версию.
