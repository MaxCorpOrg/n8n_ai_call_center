# Возражения и ответы (RU)

## Есть поставщик

- Смысл ответа: не спорить с текущим поставщиком, предложить сравнение на тесте.
- Короткий ответ:
"Понимаю. Предлагаю сравнить на тестовом объеме по вашим рабочим критериям: переносимость, скорость эффекта и экономика процедуры."

## Дорого

- Смысл ответа: подтвердить вопрос цены, перевести в ценность и формат входа.
- Короткий ответ:
"Понимаю. Давайте сравним не только цену упаковки, а итог по процедуре и возврату клиента. Могу предложить небольшой тестовый вход."

## Не работаю с пептидами

- Смысл ответа: это квалификационный факт, не давить.
- Короткий ответ:
"Принял. Тогда не буду занимать время. Если захотите расширить направление, вернемся к вопросу."

## Скиньте контакты на телефон

- Смысл ответа: согласиться, уточнить только номер для SMS и зафиксировать follow-up.
- Короткий ответ:
"Конечно, отправлю SMS с контактами. На этот номер отправить или на другой? После отправки сразу согласуем удобное время для короткого follow-up."

## Не интересно

- Смысл ответа: мягко закрыть с возможностью отложенного касания.
- Короткий ответ:
"Понял вас. Чтобы не терять контакт, могу отправить короткое КП и вернуться в удобный для вас день."
