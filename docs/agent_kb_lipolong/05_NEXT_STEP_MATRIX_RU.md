# Матрица исходов звонка и follow-up

## Статусы исхода

- `order_test` — согласован тестовый заказ.
- `manager_call` — назначен созвон с менеджером.
- `callback_scheduled` — назначен повторный звонок.
- `send_kp_pending_callback` — отправка КП или SMS + ожидается звонок.
- `not_target` — нерелевантный контакт.
- `refusal_soft` — отказ без конфликта, возможен отложенный контакт.
- `dnc` — не беспокоить.

## Правила по касаниям

- Максимум `3` активных касания на контакт.
- Если после 3 касаний нет динамики — архив в "холодный follow-up".
- Если клиент просит позже — обязательно фиксировать точные дату и время.
- Если перезвон в пределах `48 часов`, уточнять `первая половина дня / вторая половина дня`.
- Если перезвон через `3-7 дней`, фиксировать день; точное окно уточнять только если клиент сам готов его назвать.

## Как выбирать статус

- `callback_scheduled` — только если клиент явно согласовал день или ближний конкретный коридор.
- `send_kp_pending_callback` — если SMS или информация отправлены, интерес есть, но точный follow-up не подтвержден.
- `refusal_soft` — если есть мягкий отказ без конфликта и без подтвержденного следующего шага.

## Что фиксировать после каждого звонка

- Кто ЛПР и подтвержден ли ЛПР.
- Текущий поставщик/препарат (если назвали).
- Ключевая боль.
- Ключевое возражение.
- Следующий шаг.
- Время следующего контакта.
- Ответственный менеджер.
