# Команды Telegram

## Базовые
- `/start` — показать приветствие и короткую инструкцию
- `/help` — показать список команд
- `/settings` — показать текущие город и лимит
- `/debug` — показать состояние инструментов и последние fetch trace

## Настройки
- `/city Москва`
- `/city Санкт-Петербург`
- `/count 45`
- `/count 100`

## Запуск поиска
- `найди 30 косметологов в Москве`
- `запусти поиск по Казани на 25 контактов`
- `собери ещё 40 новых косметологов в Екатеринбурге`

## Что вернёт бот
При успешном запуске бот возвращает:
- название созданной таблицы
- ссылку на Google Sheets
- путь к локальному `.xlsx`
- число найденных контактов

## Ограничения
- агент настроен именно на поиск косметологов
- если новых контактов меньше нужного количества, сервис вернёт ошибку и бот покажет это пользователю
