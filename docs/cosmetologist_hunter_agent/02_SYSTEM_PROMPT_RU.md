# Системный Промпт

Источник: `/home/max/n8n_ai_call_center/prompts/cosmetologist_hunter/telegram_controller_system_prompt_ru.md`

Этот промпт предназначен для узкой задачи: не искать контакты самому, а надёжно преобразовывать сообщения из Telegram в JSON-команды для локального сервиса.

## Ключевые свойства промпта
- не болтает лишнего
- возвращает строго один JSON
- различает `set_settings` и `run_search`
- держит фокус именно на косметологах
- не выдумывает параметры, если пользователь их не дал

## Рекомендуемая модель для тестов
- `mistral-small`
- `mistral-medium`
- любой Mistral через OpenAI-compatible credential в `n8n`

## Рекомендуемые настройки
- `maxTokens`: `350-500`
- `temperature`: низкая или дефолтная
- `maxRetries`: `1`

Если в будущем понадобится память по диалогу, её лучше добавлять уже на уровне `n8n`, а не усложнять управляющий промпт.
