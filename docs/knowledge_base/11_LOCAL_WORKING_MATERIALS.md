# 11. Локальные рабочие материалы в репозитории

## Назначение

Этот файл описывает локальные рабочие материалы в `/home/max/n8n_ai_call_center`, которые не относятся к core-runtime проекта, но являются полезными артефактами для новых агентов, операторов и инженеров.

Важно:
- это не "мусор" по умолчанию;
- часть материалов можно и нужно хранить в git;
- перед удалением или игнором нужно сначала понять назначение конкретной папки;
- `Postgres/key.txt` хранит локальный helper-ключ и должен оставаться вне git.

## Проверенные рабочие каталоги

### `agent_contact_parser_docs/`
- Назначение: документация для отдельного инструмента парсинга контактов.
- Состав: `00_INDEX.md` ... `09_OPERATIONS_AND_SECURITY.md`.
- Статус: рабочая документация, допустимо хранить в git.
- Для чего полезно:
  - новый агент быстро понимает пайплайн сбора контактов;
  - видно, как заполняются Excel-таблицы под call center;
  - можно дорабатывать как отдельный subscope проекта.

- Состав: CSV-выгрузки вызовов и PDF-чек/акт.

- Важно: содержат реальные операционные данные по вызовам; коммитить можно только осознанно.

## Что считать локальными техническими хвостами

### `scripts/__pycache__/`
- Назначение: Python cache.
- Статус: технический мусор, должен игнорироваться git.

### `backups/`
- Назначение: снимки live-состояния, экспортов и промежуточных backup-артефактов.
- Статус: полезно для локальной диагностики, но это не основной исходный код.
- Политика: не удалять автоматически без отдельного решения.

### `Postgres/key.txt`
- Назначение: локальный helper-файл для агентов.
- Статус: должен существовать локально, но не должен попадать в git.
- Политика: путь добавлен в `.gitignore`.

## Правила для новых агентов

1. Не считать untracked-папку мусором только потому, что она untracked.
2. Сначала проверить состав, формат и назначение.
3. Если это операционные данные или справочные материалы, описать их в docs и только потом решать, коммитить ли их.
4. Если это секреты или helper-ключи, не коммитить.
5. Перед переименованием каталогов с пробелами сначала обновить все ссылки и docs.
