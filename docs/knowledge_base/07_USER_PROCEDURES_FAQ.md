# 07. Процедуры для пользователей и FAQ

## 1) Подключение и базовое использование
1. Открыть Telegram-бота.
2. Написать `привет`.
3. Выбрать движок (`Flow` или `Pollinations`).
4. Дать бриф или готовый промпт.
5. Подтвердить фото: `ПОДТВЕРЖДАЮ ФОТО`.
6. Подтвердить видео: `ПОДТВЕРЖДАЮ ВИДЕО`.

## 2) Быстрые команды
- `/engine flow`
- `/engine pollinations`
- `/flowcfg model=... aspect=... size=... format=... person=...`

## 3) FAQ

**Q: У меня уже есть промпт. Нужно отвечать на весь опрос?**
A: Нет, бот должен уточнить только недостающее и перейти к генерации.

**Q: Можно перегенерировать фото?**
A: Да. Напишите: `не нравится`, `переделай`, `другой вариант`.

**Q: Почему доступ к боту ограничен?**
A: Включена политика owner-only. Доступ выдаёт владелец.

**Q: Что делать при ошибке Gemini/Flow?**
A: Переключиться на Pollinations и повторить шаг.

**Q: Где посмотреть память чата в PostgreSQL?**
A: Открой Adminer по HTTPS (`https://${ADMINER_DOMAIN}`), выбери `PostgreSQL`, подключись к `postgres_memory`, открой таблицу `agent_memory`.

**Q: Можно ли править записи памяти вручную?**
A: Да. В Adminer доступны просмотр, SQL-команды и ручное редактирование строк таблицы `agent_memory`.
