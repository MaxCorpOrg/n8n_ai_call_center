ПАКЕТ МИГРАЦИИ N8N: SQLITE -> POSTGRES
Дата: 2026-05-25

Здесь лежит короткий рабочий пакет для переноса основного n8n с SQLite на Postgres.

Файлы:
1. 01_MIGRATION_PLAN.txt
   Пошаговый план миграции.

2. 02_CUTOVER_CHECKLIST.txt
   Что проверить перед переключением и сразу после него.

3. 03_ROLLBACK_PLAN.txt
   Что делать, если после переключения что-то пошло не так.

4. 04_CURRENT_RISKS.txt
   Почему эта миграция вообще нужна именно сейчас.

5. 05_CHECKPOINT_FOR_NEW_CHAT.txt
   Короткая контрольная точка: что уже сделано, где остановились, что делать дальше.

6. 06_NEW_CHAT_START_MESSAGE.txt
   Готовый текст, который можно вставить в новый чат, чтобы следующий агент сразу вошёл в контекст.

Главная мысль:
- postgres_memory уже есть;
- call_center Postgres уже есть;
- слабое место сейчас не memory-слой, а основной n8n на SQLite.
